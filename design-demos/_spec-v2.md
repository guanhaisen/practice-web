# 设计 Spec v2 · 现代克制「像好产品」

> v1 三版全部塌进「朱红 + 宋体 + 考卷/印章」的框,用户判定太传统/土。**本版彻底放下那条线**。重读庄重 = 冷静、自信、靠留白与层级说话,像真正好用的当代产品,不挂任何传统符号。
> 本文件是 v2 三版的唯一共同输入,三个方向严格共用同一份真实内容,只换设计语言,不得编造数据、不得互相参考。

## 1. 气质(重述)
庄重 = 冷静、可信、克制。靠排版、留白、层级、单一克制的强调色建立,**不靠印章/考卷/宋体刊头/传统纹样**。像 Linear / Things / 精致闪卡工具 那种「好产品」的安静自信。

## 2. 硬约束(红线)
- **禁止 v1 那套**:禁止朱红印章、禁止考卷双线外框、禁止「绝密★启用前」条、禁止宋体刊头、禁止发丝线网格目录那种"出版物"味。
- **配色**:中性底(近白 / 暖白 / 纯白自选)+ 墨色文字 + **单一克制强调色**。三版各自选不同 accent,且只用于:当前 Tab、进度、判分对错、主按钮。强调色不铺满背景。
  - v2-1 accent:**沉静靛蓝**(如 #3b5bdb 降饱和版 / #2f4a7c)
  - v2-2 accent:**克制陶土 / 赭红**(精炼品牌红,如 #c2410c / #b45309,**不是考卷红**)
  - v2-3 accent:**近黑白 + 一抹深青或森林绿**(如 #0f766e / #14532d)
- **字体**:无衬线主导。`Noto Sans SC`(Google Fonts CDN)+ 系统回退 `"PingFang SC","Microsoft YaHei",sans-serif`。西文/数字可用一款精炼无衬线(如系统 -apple-system / "Segoe UI")。**禁止**宋体刊头、**禁止** Arial 兜底中文、**禁止** Inter 当中文 display。
- **反 slop**:禁止紫渐变;禁止 emoji 当图标(可用中性几何/文字符号);禁止圆角卡 + 左彩条(卡片可用均匀细边框 #ececec,但绝不在左侧加一道彩色竖条);禁止 blue-600 + zinc 默认组合;禁止无内容装饰。

## 3. 输出格式(三版统一,否则无法对比)
- 单文件 HTML,CSS 内联,双击可开。
- 每文件含**两个屏幕**:① 首页(选科仪表盘)② 练习页(刷题核心)。页面顶部做一个极简切换条(两个文字按钮「首页 / 练习页」+ 当前方向标签,无边框或仅发丝线),一小段 <script> 控制显隐,**默认显示首页**。
- 视口 1440×900 内呈现;内容区 max-width 约 1000–1080px 居中。
- 中文 CDN 字体 + 系统回退,保证中文不丑。

## 4. 真实内容(禁止编造)
- 应用名:**大学生刷题**
- 14 科目:高等数学(上)、高等数学(下)、大学英语 I、大学英语 II、大学英语 III、党史、马克思主义原理、大学物理、线性代数、概率数理统计、思想道德与法治、中国近现代史纲要、毛泽东思想和中国特色社会主义理论体系概论、形势与政策;兜底「综合练习」。
- **诚实呈现进度**:当前内置仅「党史」有 680 题,其余科目为「待导入」;卡片上 错题/难题/待复习 显示 0 或 —,**不要编造进度数字**。
- 真实样例题(党史 ds-1,必须原样):题干「中国共产党一经成立,就把实现()作为党的最高理想和最终目标。」选项[共产主义/社会主义/资本主义/帝国主义] 答案:共产主义 类型:单选。练习页展示「已提交·回答正确」态:正确项标识 + 参考答案「共产主义」+ 解析区(空则写「(本题暂无解析)」)。

## 5. 三版差异化任务(各自独立,内容完全一致,骨架必须互异)
- **v2-1 · 冷静效率**:参照精致现代效率 / 学习 App(如 Things、精致闪卡工具、Linear 的克制)。靛蓝强调。首页 = 克制卡片网格(均匀细边框 #ececec、无左彩条),每卡含科目名 + 共 N 题 / 待导入 + 进度条/环 + 错题/难题/待复习(0 或 —)+ 综合练习兜底卡;底部入口行 + 修改选科。练习页 = 居中单卡,模式 Tab(当前态用靛蓝下划线/细填色)、顺序/随机、细进度条、题干、选项整行细边框(选中 = 靛蓝描边而非填充)、提交 = 实色靛蓝主按钮、答案区。
- **v2-2 · 暖人文克制**:参照温暖现代编辑 / 阅读学习产品( humane、warm、calm)。陶土/赭红强调(精炼品牌红)。首页 = 宽松**单列索引**(非密铺网格),每行科目名 + 状态 + 错题/难题/待复习,发丝分隔,大量留白;练习页 = 宽松页边、题干舒适、选项干净边框行、强调色仅用于关键标记。
- **v2-3 · 高对比极简**:参照画廊 / 美术馆级极简产品 identity(Pentagram 式)。近黑白 + 一抹深青/森林绿。首页 = **大字排版索引**(科目大标题、极少 chrome、强层级);练习页 = 大胆留白、超大题号、极简选项。首屏必须有清晰视觉锚点(大字标题 + 一处强调色),绝不允许死白 + 微缩字。

## 6. 可读性硬底线
正文 ≥14px、标签/注释 ≥12px、正文对比度 ≥4.5:1。留白是构图不是缺席。
