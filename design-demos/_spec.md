# 设计 Spec · 大学生刷题 UI 重做

> 本文件是三套方向稿的**唯一共同输入**。三个方向严格共用同一份真实内容与约束,只换设计语言,不得编造数据、不得互相参考。

## 1. 产品是什么
「大学生刷题」是一个**本地优先**(数据存 localStorage,无后端)的题库练习 Web App,面向大学生备考。当前内置 **680 道党史题**,科目体系涵盖 **14 门**:
高等数学(上)、高等数学(下)、大学英语 I、大学英语 II、大学英语 III、党史、马克思主义原理、大学物理、线性代数、概率数理统计、思想道德与法治、中国近现代史纲要、毛泽东思想和中国特色社会主义理论体系概论、形势与政策;另有兜底入口「综合练习」(含全部示例)。

## 2. 目标受众与使用场景
- 受众:正在期末 / 考研 / 考公的大学生。
- 场景:图书馆、宿舍、通勤;从碎片时间到整块时间都在刷。
- 核心需求:快速进入刷题、看清对错与解析、追踪薄弱点。
- 情绪基调:**认真、要紧**——不是娱乐,不是玩具。

## 3. 核心信息与内容要点(真实数据,禁止编造)
- 应用名:**大学生刷题**
- **首页(选科仪表盘)**:
  - 标题「大学生刷题」+ 副文案「已选科目,点击开始练习;进度按科目自动保存在本地。」
  - 已选科目卡片网格,每卡含:科目名、共 N 题 · 已做 X/N、错题数(红)、难题数(琥珀)、待复习数(靛)、重置按钮。
  - 兜底入口卡片:「综合练习(680 题,含全部示例)」。
  - 底部入口行:导入 / 管理题库、练习历史、错题本、导出备份。
  - 底部按钮:修改选科(进入勾选 14 科的选择态)。
- **练习页(刷题核心)**:
  - 顶部:← 退出(进度已保存) + 科目名。
  - 模式 Tab:全部 / 错题 / 难题 / 背题 / 复习;右侧 顺序⟳ / 随机🔀 切换。
  - 进度区:已答 X/N、正确率 %、进度条、剩余 N 题(背题/复习模式不显示)。
  - 题目卡:题型标签(单选/多选/判断/填空)、第 X/N 题、标记★、上一题。
  - 题干(可多行);选项(单选/多选点选高亮,填空为输入框);提交 → 判分(绿对/红错)+ 参考答案 + 解析 + 下一题。
  - 背题/复习模式:显示答案 / 记住了·没记住。
  - 完成后:本次刷题完成 🎉 + 统计 + 重新开始 / 查看错题。
- **真实样例题(党史 ds-1,必须原样使用)**:
  - 题干:「中国共产党一经成立,就把实现()作为党的最高理想和最终目标。」
  - 选项:共产主义 / 社会主义 / 资本主义 / 帝国主义
  - 答案:共产主义
  - 类型:单选

## 4. 情感基调与气质(已与用户确认:严肃学术 / 庄重)
庄重、克制、可信,像正经学习资料 / 学术出版物,而非玩具或 SaaS 落地页。编辑式排版、清晰层级。
**反 AI slop 硬约束**:禁止紫渐变;禁止 emoji 当图标(🔀⟳ 这类可用中性符号或文字,不要花哨 emoji);禁止圆角卡片 + 左彩条;禁止通用蓝(blue-600)+ 灰(zinc)默认组合;禁止 Inter/Roboto/Arial 当中文 display;禁止无内容装饰。

## 5. 输出格式与尺寸(三版必须统一,否则无法横向对比)
- **单文件 HTML**,CSS 全部内联,不依赖任何构建 / 框架,双击即可在浏览器打开。
- 每个文件包含**两个屏幕**:① 首页(选科仪表盘)② 练习页(刷题核心)。用页面内顶部两个按钮「首页 / 练习页」切换显隐,**默认显示首页**。
- 视口内呈现 1440×900;内容区 max-width 约 960–1100px 居中(模拟真实 App 的窄栏阅读宽度),不是铺满整屏。
- 中文排版:使用 `Noto Serif SC` / `Noto Sans SC`(Google Fonts CDN `<link>`),系统回退 `"Source Han Serif SC","Songti SC",serif` 等;**禁止**用 Arial 兜底中文。
- 可通过 CDN 引入字体;若离线,必须有合理的系统衬线/黑体回退,保证中文不丑。

## 6. 已知约束
- **配色**:以墨黑 / 纸白为底。**唯一强调色用克制的深红(约 #9a1f1a–#b22222 区间,即朱/绛)或墨色**,不得用亮蓝、紫。深红仅用于关键标记(对错、品牌印、当前 Tab 下划线),不铺满背景。
- **字体**:标题可用衬线(宋 / 思源宋)建立学术感;正文清晰无衬线或衬线皆可,但须有「审校过」的排印细节(`text-wrap: pretty`、合理行高 1.6–1.8、适当字距、标点处理)。
- **暗色**:本次以浅色(纸白)为正。可附一个克制的暗色变体区块,但非必须。

## 7. 图片需求
本应用为工具 / 数据型,**不需要照片**。视觉靠排版、网格、线条、字体、单一红色印记(可作 wordmark / 印章)驱动。不要塞装饰 stock 图——那会沦为 slop。

## 8. 视觉母题假设(从内容长出来,三版各自发展其一)
党史 + 考卷 + 学术资料。可发展母题:
- ① **编辑式分栏 + 发丝级分隔线**(像严肃期刊 / 学术辑刊);
- ② **试卷 / 教材的边框盒与题号系统**(像真实考卷 / 教材页);
- ③ **留白 + 一道朱红竖线 / 印章印记**(像典籍批注 / 现代学术品牌)。
三版各取其一,**骨架必须互异**(首页的卡片网格 vs 列表/分栏;练习页的题目卡结构至少一项结构性不同),不许两版共用同一骨架只换色换字体。

## 9. 可读性硬底线(任何风格温度都不豁免)
正文 ≥14px、标签 / 注释 ≥12px、正文对比度 ≥4.5:1。留白必须是**构图**(首屏有明确视觉锚点,视线有落点),不是内容缺席——安静派做过头 = 大片死白 + 微缩字号 = 像页面渲染坏了。

## 10. 三版任务分配(各自独立,只换设计语言,内容完全一致)
- **方向一 · 编辑学术 / Swiss-serif 期刊感**:参照严肃学术辑刊 / 大学出版社 identity。发丝线分隔、网格、衬线 display 标题(Noto Serif SC),克制深红用于判分与当前标记。首页用编辑式分栏/网格;练习页单列、题干预排精致。
- **方向二 · 考卷文档 / 印章红 教材感**:参照真实印刷考卷 / 教材页。边框盒、题号系统(一、二、三 / 1. 2. 3.)、一个朱红「印」式 wordmark 作品牌,选项像答题区。首页像「目录 / 卷次」列表;练习页像一张真实试卷。
- **方向三 · 克制留白 / 顶级学术品牌 安静派**:体现顶级设计师的安静学术 identity(如 Pentagram 式现代大学 / 美术馆标识)。大量留白、一道朱红竖线或印记、精炼黑体/衬线混排、安静层级。**首屏必须有清晰视觉锚点**(不要死白)。

交付:每个方向写一个 HTML 文件到 `design-demos/direction-1.html`(方向一)、`direction-2.html`、`direction-3.html`。文件名严格对应。只 Write 自己的文件,不要读 design-demos 下其他 HTML,不要运行 npm / build / dev。
